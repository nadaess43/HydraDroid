# Бесконечная лента главной (Home infinite feed)

Статус: РЕАЛИЗОВАНО в `ui/screens/HomeCatalogue.kt` (FeedState по табам, take 12→24,
snapshotFlow-триггер, футер спиннер/«Это всё»/«Повторить»).
Дополнительно: сетка по брейкпоинтам home.scss (1/2/3/4), фильтр downloadSourceIds.

## Контекст (порт!)
Оригинал `hydra/src/renderer/src/pages/home/home.tsx`: Hero + табы
`hot | weekly | achievements` + «Surprise me», фиксированные 12 игр на таб,
пагинации нет. На телефоне 12 игр — мало, поэтому делаем аккуратное
расширение оригинала: те же табы и порядок, но лента догружается сама.
Визуал (Hero, кнопки primary/outline, сетка 8dp, скелетоны) не меняется.

## Текущее состояние (`ui/screens/HomeCatalogue.kt`)
- `cache: Map<tab, List<...>>`, первая страница `getCatalogueCategory(tab, take=12, skip=0)`.
- Возврат на таб сеть не дёргает. Ошибка первой страницы — пустой экран + «Повторить».

## План
1. **Состояние по табам**: `Map<tab, FeedState(games, hasMore=true, loadingMore=false, failedPage=false)>`.
   Переключение табов сохраняет подгруженное.
2. **Первая страница** — как сейчас (`take=12, skip=0`). Вернулось меньше 12 → `hasMore=false`.
3. **Триггер** — `rememberLazyGridState()` + `snapshotFlow` на
   `layoutInfo.visibleItemsInfo`: последний видимый в пределах ~6 карточек
   от конца + `hasMore && !loadingMore` → `loadMore()`. Флаг защищает от дублей.
4. **Следующие страницы** — `getCatalogueCategory(tab, take=24, skip=games.size)`.
   Append с дедупликацией по `shop:objectId`. Пустая/короткая страница → `hasMore=false`.
5. **Футер сетки** (`GridItemSpan(maxLineSpan)`): спиннер при `loadingMore`,
   «Это всё» при `!hasMore`, «Повторить» при `failedPage` (ошибка страницы
   не роняет ленту).
6. **Смена таба во время загрузки** — ответ сверяется с текущим табом, чужой
   игнорируется; `loadingMore` сбрасывается.
7. **Без изменений**: Hero, табы, «Мне повезёт» (рандом по загруженному),
   счётчик секции, сетка/отступы/скелетоны.
8. **Проверка**: `assembleDebug`; скролл 2–3 страницы на каждом табе;
   переключение табов (без повторной сети); airplane-mode на 2-й странице
   (ошибка только футера + «Повторить»).

## Допущение
Сервер корректно обрабатывает `skip` (пусто/коротко в конце). Если `skip`
игнорируется — дедупликация поглотит дубли, `hasMore` выключится по признаку
«все элементы уже есть» (запасной вариант).
